# 로망휘트니스 홈페이지 시안

로망휘트니스(고척신정점 · 영등포점 · 파주교하점) 홈페이지 시안 모음입니다. 내부 검토용이며 실제 홈페이지가 아닙니다.

- 미리보기: https://example-preview.github.io/
- 새 시안 G~L: 타 업종 대기업 22곳의 홈페이지 구성을 벤치마킹해 만든 여섯 가지 구조 (`g-checkin.html` ~ `l-compare.html`)
- 이전 시안 A~F, 벤치마크 페이지(`benchmark.html`)

## 공개 전 주의
- `assets/img/sample/`의 사진은 레이아웃 확인용 샘플(유명 선수, 위키미디어 커먼즈 CC 라이선스, 출처는 `NOTICE.txt`)입니다. 로망휘트니스 트레이너나 수상 실적이 아닙니다. 실제 오픈 전 반드시 자체 사진으로 교체합니다.
- 트레이너 프로필 사진은 웹 게재 동의 확인 전입니다.
- "예시" 태그가 붙은 문구와 후기는 지어낸 예시입니다.
- 평점·리뷰 수·가격은 네이버 플레이스 2026년 11월 기준입니다.
- 모든 페이지에 검색엔진 비노출(noindex) 태그가 있습니다.
